# Primary dashboard evidence

The primary account’s dashboard showed **5 saved**, **5 visited**, and an average rating of **4.2**. Its cuisine counts were Colombian 1, Dominican 1, Nigerian 2, and Thai 1, totaling five restaurants.

The five actual user ratings total 21.2; `21.2 ÷ 5 = 4.24`, displayed to one decimal as 4.2. The calculation uses those ratings only; no ratings or restaurant notes were invented for this evidence.
